# Interface fonts

The UGA Visual Style guide approves Oswald and Merriweather Sans.
The dashboard uses the bundled variable fonts at weights 500 and 400, respectively.

- Oswald: Copyright 2016 The Oswald Project Authors. See `Oswald-OFL.txt`.
- Merriweather Sans: Copyright 2019 The Merriweather Project Authors. See `MerriweatherSans-OFL.txt`.

Both fonts use the SIL Open Font License 1.1. The original font files retain their embedded copyright and license metadata.
